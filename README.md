# IPMI/BMC 直连助手

<p align="center">
  <img src="ezgetBMCIP.svg" width="120" alt="ezgetBMCIP 标志"/>
</p>

ezgetBMCIP 用于笔记本通过独立有线网卡直连服务器的 IPMI/BMC 专用管理口，临时建立直连网络并协助确认管理地址。

## 适用与不适用

- 仅用于笔记本与服务器 IPMI/BMC 专用管理口的一对一直连。
- 选择一块独立的有线网卡；运行期间这块网卡不能承担上网、远程桌面或业务连接。
- 不要把所选网卡接入交换机、业务网、已有局域网或普通服务器网口。
- 程序需要管理员权限，启动时会请求 UAC 提权。

## 快速使用

1. **确认影响**：阅读使用风险告知；不同意时不会修改网卡。
2. **选择网卡**：选择直连 BMC 的独立有线网卡，需要时调整临时私有网段。
3. **确认网络修改**：核对所选网卡、临时地址和恢复方式后开始。
4. **接入管理口**：将网线接到服务器的 IPMI/BMC 专用管理口。
5. **等待获取与验证**：工具配置本机直连网络，等待 BMC 获取地址并检查管理访问。
6. **打开页面**：管理服务验证后，打开管理页面完成操作。
7. **恢复并退出**：完成后点击“恢复网卡并退出”，再按现场方案恢复接线。

## 运行期间会发生什么

- 工具只会修改并恢复所选的本机网卡，不会修改 BMC 的网络设置。
- 工具会为所选网卡设置临时地址并启动临时 DHCP；该网卡原有网络会断开。
- **候选地址**是可能属于 BMC 的地址，不等于管理页面已经可用。
- **已验证可达**表示从所选网卡获得了连通证据；**管理服务响应**才表示 HTTPS 或 HTTP 管理访问已经通过验证。
- **已请求打开浏览器**只表示已向系统发出打开请求，不表示网页已经加载成功。
- 正常退出时，工具停止自身 DHCP 并恢复原配置。原来使用 DHCP 的网卡会重新获取租约，地址可能不同；原来使用静态地址的网卡会按记录写回 IPv4、网关和 DNS。

## 能做什么

- 选择目标有线网卡，并使用私有 IPv4 网段建立直连。
- 显示“建立直连 → 获取地址 → 验证访问”的当前状态。
- 区分候选地址、可达性、管理服务验证和浏览器打开请求。
- 在防火墙风险、超时或恢复异常时给出下一步和支持包入口。
- 停止临时 DHCP，并恢复所选网卡已记录的网络配置。

## 自定义网段

默认本机临时地址为 `10.77.77.1/24`，预期 BMC 地址为 `.100`。需要避让已有网段时，只能使用私有 IPv4 网段：

- `10.x.x.x`
- `172.16.x.x` 到 `172.31.x.x`
- `192.168.x.x`

## 遇到问题

### 一直等待 DHCP

检查网线是否插在服务器的 IPMI/BMC 专用管理口，并确认所选网卡不是普通业务网口。

### Windows 防火墙提示或等待超时

在 Windows 弹窗中按实际网络类型允许程序；出现“公用网络”选项时必须勾选。超时页面出现“处理防火墙并准备重试”时，按提示重新检查和确认处理范围。

### 已有候选地址但页面未响应

先点击“重新检测”；仍未响应时，在“其他方式”中手动尝试 HTTPS 或 HTTP。

### 恢复失败或异常退出

重新连接目标网卡后再次启动工具恢复；仍无法恢复时导出支持包。

## 提供支持信息

按 `Alt+L` 或点击“导出支持包”收集日志。提交时同时说明操作步骤、所选网卡、页面提示和是否出现 Windows 防火墙弹窗。
