# Privacy Policy

ezgetBMCIP does not collect, store, or transmit any personal information.

This program operates entirely on the local machine and local network segment.
It does not connect to any remote servers, analytics services, or cloud systems.

All network activity is limited to:
- Configuring a local network adapter (10.77.77.x subnet)
- Running a DHCP server on the local machine
- Opening the IPMI/BMC web interface in the user's default browser

No user data of any kind is collected or transferred.
