# IPMI/BMC 直连助手 1.5.8

## 本版重点

- 修复 DHCP ACK 后 Windows 网卡短暂重新枚举导致的误失败。端点验证不再只按原始 GUID 精确查找网卡。
- 端点确认改为最多约 5 秒的并行轻量检测：Ping、TCP 443 和 TCP 80。
- Ping 或任一 TCP 端口连接成功即判定候选地址可达；网页内容、TLS、HTTP 状态码和非常用端口不参与成功判断。
- 443/80 均不可连接时仍保留已分配地址并提示重新检测，不再等待 45 秒或调用同步 ARP/HTTP 验证。
- 现代版与 Legacy 共用相同的地址可达语义、浏览器选择和诊断字段。

## 保持不变

- DHCP DORA、`.100` 已知地址并行探测和安全恢复机制保持不变；旧地址改用同一套轻量可达性检测。
- 历史记录保存地址可达证据，并兼容读取旧版 HTTP 响应记录；不保存凭据或网页内容。
- 工具不会自动恢复 BMC 网络设置，不会自动修改防火墙；失败时保留当前会话供用户重新验证或明确恢复退出。

## 适用版本

- Win10/11 x64 Full：自包含单文件。
- Legacy：Windows 7 SP1、Windows 8、Windows 8.1；需要 .NET Framework 4.6 或更高版本，并应保留完整文件夹。
