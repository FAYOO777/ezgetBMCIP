# IPMI/BMC 直连助手 1.5.6

## 适用版本

- Win10/11 x64 Full：自包含单文件，不需要单独安装 .NET Desktop Runtime。
- Legacy：Windows 7 SP1、Windows 8、Windows 8.1；需要 .NET Framework 4.6 或更高版本，部署时必须保留整个文件夹。

## 本版重点

- 仅在 DHCP 等待满 3 分钟且没有发现明确防火墙 Block 时，工具会提示同一块网卡上一次成功使用的 BMC 网段。
- 选择“使用上次网段准备重试”后，工具会先停止当前 DHCP 并恢复本机网卡，再预填上次本机网段；不会自动开始，也不会修改 BMC 或防火墙。
- 同一应用运行中只提示一次历史网段。用户手动重新开始后若仍失败，请直接导出支持包继续排查。
- 成功确认 BMC HTTP/HTTPS 管理端口后，工具会在本机保存该网卡的一条最近记录；记录不包含用户名或密码。
- 失败页面可直接导出支持包，无需记忆快捷键；`Alt+L` 仍可使用。
- Legacy 窗口现在支持手动拉伸；状态卡、历史重试提示与结果区域在窗口较小时可垂直滚动，底部“退出并恢复网卡”始终可见。
- 新增“处理防火墙并准备重试”：本轮结束且存在防火墙风险时，可重新检查规则、核对变更并确认处理。先停止 DHCP、恢复网卡，随后限定当前 EXE、目标网卡、所选网络类型添加 UDP/67 入站许可，复查后返回选择页，保留本次网段并等待手动开始。

## 已知边界

历史网段只是“上次成功情形”的提示，不能证明当前响应的设备就是同一台 BMC，也不会扫描未知网段。工具不能强制 BMC 立即放弃旧租约、切换 DHCP 或修改固定 IP。

## 防火墙说明

未确认处理前，工具只读取防火墙规则。若 Windows 弹出访问提示，请允许当前程序通过与直连网卡相符的网络类型；公用网络需勾选“公用网络”。漏选后可在本轮结束时点击“处理防火墙并准备重试”。

处理前会列出当前 EXE 的相关本机阻止规则及影响；处理只取消选定网络类型下的阻止，其他网络类型保留。原规则若覆盖所有 UDP 端口或多个接口，取消该网络类型的阻止影响也覆盖这些范围，须在确认页核对。通用阻止、来源不明的规则、域网络及限制本机规则的策略交由管理员处理。

旧系统无法确定网卡类别时，确认页明确提出按 Public 处理，用户须确认网卡实际属于公用网络。工具不关闭防火墙、不更改 BMC。许可规则保留供后续使用，不随退出撤销；变更前备份至 `%LOCALAPPDATA%\ezgetBMCIP\FirewallBackups`，执行失败时尝试回滚并报告结果。规则复查通过不代表设备一定会发来 DHCP 请求。
