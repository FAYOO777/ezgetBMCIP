# IPMI/BMC 直连助手 1.5.7

## 本版重点

- 管理地址不再只因 TCP 443/80 可以连接而被判定成功。工具会从所选直连网卡验证路由和 ARP 邻居，并完成最终的 HTTP 或 HTTPS 管理服务响应（2xx、3xx、401 或 403）后，才显示管理服务已响应。
- HTTPS 自签名证书可用于 BMC 可达性验证；工具会显示协议和 HTTP 状态，但不会声称已验证外部浏览器完成网页加载。
- `.100` 旧租约回退继续与 DHCP 并行，但只有通过上述完整验证才会结束 DHCP 等待；TCP 假连接、HTTP 1xx、代理认证 407、服务端 5xx、代理或 TUN 接管都不会直接产生成功页或成功历史。
- 旧版仅凭 TCP 端口写入的本机历史记录会自动失效。新版只保存经真实 HTTP/HTTPS 响应确认的最近记录，不包含凭据或网页内容。
- 防火墙处理现在可以区分 Windows 为同一 EXE 自动生成的同名 TCP/UDP 规则；只处理当前 EXE、当前网络类型的 UDP 入站阻止，不改动同名 TCP 规则。

## 防火墙与代理说明

- 防火墙处理仍须用户明确确认；先恢复网卡，再限定当前 EXE、所选网卡和 UDP/67 处理规则。规则会保留，变更前备份，失败时尝试回滚。
- 工具不会关闭或修改 Mihomo、VPN、代理或 BMC 的网络设置。若工具已直接收到管理服务响应但浏览器仍无法打开，请暂停代理/VPN，或为直连网段设置绕过规则。
- 支持包新增端点验证阶段、ARP/路由、代理状态和防火墙规则身份信息，便于区分 DHCP、防火墙、代理和 BMC Web 服务问题。

## 适用版本

- Win10/11 x64 Full：自包含单文件。
- Legacy：Windows 7 SP1、Windows 8、Windows 8.1；需要 .NET Framework 4.6 或更高版本，并应保留完整文件夹。
