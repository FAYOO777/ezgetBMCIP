# IPMI/BMC 直连助手 2.0.2

## 本版重点

- 修复 Legacy 防火墙处理成功并完成复查后，仍显示黄色“防火墙需要留意”和重复处理入口的问题。
- Legacy 现在根据复查结果区分“防火墙许可已处理”和仍需留意的防火墙结果。
- 只有仍存在风险时才显示重新处理；处理异常时保留导出支持包入口。

## 保持不变

- 防火墙只读评估、规则处理范围、备份、复查和回滚流程不变。
- DHCP、地址探测、历史网段、浏览器启动和网卡恢复流程不变。
- Full 和 Lite 共用正式版界面逻辑，本版不改变其现有动态防火墙结果展示。
- 本版本属于本地支线，不创建正式 Git tag、不上传发布物、不修改线上版本索引。

## 适用版本

- Win10/11 x64 Full：自包含单文件。
- Lite：需要目标机已安装 .NET Desktop Runtime 8 x64。
- Legacy：Windows 7 SP1、Windows 8、Windows 8.1；需要 .NET Framework 4.6 或更高版本，并应保留完整文件夹。
