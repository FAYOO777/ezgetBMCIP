# IPMI/BMC 直连助手 1.5.5

## 适用版本

- Win10/11 x64 Full：自包含单文件，不需要单独安装 .NET Desktop Runtime。
- Legacy：Windows 7 SP1、Windows 8、Windows 8.1；需要 .NET Framework 4.6 或更高版本，部署时必须保留整个文件夹。

## 本版重点

- 修复跨网段旧 DHCP 租约：旧网段请求不会再被错误确认；工具会按 DHCP 规则返回 NAK，等待设备重新发起可用请求。
- 改进 Windows 防火墙诊断：在改网卡前检查当前 EXE 路径、UDP/67 与规则冲突；DHCP 监听器打开后再检查一次，覆盖 Windows 运行中才生成阻止规则的情况。
- 发现明确 Block 时，提示会指出当前 EXE 与防火墙原因，避免无意义地等待 DHCP 超时。
- Windows 7/8.1 采用只读 Windows Firewall COM 回退，旧系统不能完整判定网卡类别时会保守警告，不会把未知状态误报为安全。
- 修复 Windows 7 Legacy 启动时只读属性双向绑定导致的崩溃。
- 强化日志与支持包；在程序窗口按 `Alt+L` 可导出诊断包。

## 防火墙说明

本工具不会自动修改客户防火墙，也不建议关闭整个防火墙。若 Windows 弹出访问提示，请允许当前程序通过与直连网卡相符的网络类型；若提示明确显示“公用网络”，需要勾选“公用网络”。若页面提示“防火墙高风险”，请先处理当前 EXE 路径对应的显式 Block，再重新开始。

## 已知边界

工具能处理自身网卡配置、DHCP 服务和本机侧的诊断，但不能强制 BMC 改为 DHCP、立刻清除固定 IP 或立刻忘记旧租约。若仍未收到 DHCP 请求，请核对 BMC 网络模式、管理专用口、链路、VLAN 和 BMC 固件状态，并通过支持包排查。
