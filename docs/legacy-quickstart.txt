IPMI/BMC 直连助手 Legacy 使用教程

英文项目名：ezgetBMCIP

适用系统：
Windows 7 SP1 / Windows 8 / Windows 8.1

首次使用：
1. 如果本机还没有安装 .NET Framework 4.6，请先运行本文件夹里的：
   NDP46-KB3045557-x86-x64-AllOS-ENU.exe

2. .NET Framework 4.6 安装完成后，建议重启电脑。

3. 回到本文件夹，右键运行：
   ezgetBMCIP-legacy.exe

使用步骤：
1. 阅读“使用风险告知”，勾选确认后点击“同意并继续”。
2. 选择要连接服务器 IPMI/BMC 管理口的有线网卡。
3. 点击“开始”，阅读“网络修改告知”，核对弹窗中的临时本机 IP、BMC 临时 DHCP 地址与恢复目标，勾选确认后再开始。
4. 按提示把网线插到服务器的 IPMI/BMC 专用管理口。
5. 等待工具分配候选 IP。工具会检查 Ping、HTTPS 和 HTTP；443 连接成功时使用 HTTPS，只有 80 连接成功时使用 HTTP，两个端口都未连接时可重新检测。
6. BMC 操作完成后，回到工具点击“完成 / 退出”，等待本机网卡恢复。

DHCP 超时后的重试：
- 若这块网卡曾成功连接过其他网段的 BMC，首次等待超时后工具可能提示“使用上次网段准备重试”。
- 勾选确认后，工具会先恢复本机网卡，再填入上次网段；请自行再次点击“开始”并重新确认网络变更。
- 第二次仍失败时，请点击“导出支持包”（或按 Alt+L）提供诊断，不会重复提示历史网段。

注意事项：
- 漏勾防火墙网络类型时，本轮结束后可点击“处理防火墙并准备重试”。核对弹窗列出的规则和影响并确认后，工具先恢复网卡，再处理当前 EXE 的 UDP/67 接收许可；成功后保留本次网段，等待你手动开始。
- 防火墙处理规则会保留，退出时不自动撤销；组织策略和无法确认本机来源的阻止规则需管理员处理。变更前的备份保存在 %LOCALAPPDATA%\ezgetBMCIP\FirewallBackups。
- 这个工具只用于笔记本和 IPMI/BMC 管理口直连，不适合接入局域网使用。
- 两道告知均默认不同意；关闭或取消告知不会修改网卡。
- 运行期间会临时修改所选网卡的 IPv4 配置，并临时清空原 DNS 设置。
- 退出时只恢复所选本机网卡：原 DHCP 会恢复为自动获取并重新申请租约；原静态 IPv4、网关与 DNS 会按读取结果写回。
- 本工具不会主动还原 BMC 的网络设置；BMC 的临时 DHCP 地址请按现场网络方案处理。
- 若 Windows 弹出防火墙访问提示，请为当前直连网卡对应的网络类型允许本程序访问；若提示明确显示“公用网络”，也必须勾选“公用网络”。不要关闭整个防火墙。
- 若工具提示管理服务已响应但浏览器仍打不开，请暂停代理/VPN/Mihomo，或将本次直连网段设为绕过代理；工具不会自动修改这些第三方网络设置。
- 需要排障时，将操作步骤、错误提示和按 Alt+L 生成的支持包提供给维护人员。
