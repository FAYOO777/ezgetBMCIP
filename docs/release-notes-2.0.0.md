# IPMI/BMC 直连助手 2.0.0

## 本版定位

2.0.0 是当前本地支线的新版本基线，收敛了从 1.5.1 开始完成的网络恢复、DHCP、防火墙诊断与处理、历史网段重试、端点检测以及正式版和 Legacy 使用体验统一工作。

本文件用于本地测试包；当前不创建正式 Git tag、不上传发布物，也不修改线上版本索引。

## 适用版本

- Win10/11 x64 Full：自包含单文件。
- Legacy：Windows 7 SP1、Windows 8、Windows 8.1；需要 .NET Framework 4.6 或更高版本，并应保留完整文件夹。

## 使用边界

- 工具只临时修改并恢复所选 Windows 网卡，不会修改或恢复 BMC 的网络设置。
- 防火墙处理必须由用户明确确认，并限定当前 EXE、所选网卡、网络类型及 DHCP UDP/67 范围。
- DHCP 获得候选地址、地址或管理端口可达、请求系统打开浏览器和网页实际加载是不同状态。
- 测试结束后应使用界面中的恢复操作，等待本机网卡确认恢复后再退出或恢复现场接线。
