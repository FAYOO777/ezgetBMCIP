# IPMI/BMC 直连助手 2.0.1

## 本版重点

- 修复 DHCP 等待三分钟超时后，Legacy 在防火墙评估为 Warning 或 Unknown 时不显示防火墙处理入口的问题。
- Warning/Unknown 仍只表示存在兼容性风险或无法完整评估，不宣称防火墙就是失败原因。
- 点击“处理防火墙并准备重试”后，仍需重新只读检查、核对范围并由用户明确确认；取消不会修改网卡或防火墙。

## 保持不变

- DHCP、地址探测、历史网段、浏览器启动和网卡恢复流程不变。
- 防火墙处理仍限定当前 EXE、目标网卡、所选网络类型及 UDP/67，保留备份、复查和失败回滚。
- 本版本属于本地支线，不创建正式 Git tag、不上传发布物、不修改线上版本索引。

## 适用版本

- Win10/11 x64 Full：自包含单文件。
- Legacy：Windows 7 SP1、Windows 8、Windows 8.1；需要 .NET Framework 4.6 或更高版本，并应保留完整文件夹。
